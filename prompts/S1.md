### 4. Problem Specification: S1 — Binary Tree Traversals (`19_q3.rkt`)
A binary tree is either the empty list `'()`, or a three-element list `(value left right)`, where `left` and `right` are binary trees. `value` is a number or a single-character symbol.

**Conventions:**
- The height of `'()` is `0`; the height of a node is `1 + max(height(left), height(right))` (a single node has height `1`).
- A leaf is a node whose left and right subtrees are both `'()`. The empty tree has `0` leaves.
- Subtrees are always visited left first, then right.

**Tasks (the grader defines the trees and calls these three functions):**
- **S1.a:** `(print-inorder tree)` prints, on one line using `display`, the list of values in inorder (left, node, right), ending with a newline.
- **S1.b:** `(print-all-traversals tree)` prints three lines using `display`: the inorder list, the preorder list (node, left, right), and the postorder list (left, right, node), each ending with a newline.
- **S1.c:** `(print-height-and-leaves tree)` prints one line using `display`: the list `(height leaf-count)`, ending with a newline.

**Examples:**
- `t1 = '(4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ())))`
  - `(print-inorder t1)` -> `(1 2 3 4 5 6 7)`
  - `(print-all-traversals t1)` -> `(1 2 3 4 5 6 7)`, `(4 2 1 3 6 5 7)`, `(1 3 2 5 7 6 4)`
  - `(print-height-and-leaves t1)` -> `(3 4)`
- `t2 = '(1 () (2 () (3 () ())))`
  - `(print-all-traversals t2)` -> `(1 2 3)`, `(1 2 3)`, `(3 2 1)`
  - `(print-height-and-leaves t2)` -> `(3 1)`
- `t3 = '(a (b () ()) (c () ()))`
  - `(print-all-traversals t3)` -> `(b a c)`, `(a b c)`, `(b c a)`
  - `(print-height-and-leaves t3)` -> `(2 2)`
- Empty tree `'()`:
  - `(print-inorder '())` -> `()`
  - `(print-all-traversals '())` -> `()` on all three lines
  - `(print-height-and-leaves '())` -> `(0 0)`

Confirm in one sentence that you have read `skill.md` and these rules, and wait for Prompt 1. Do not write any code yet.
