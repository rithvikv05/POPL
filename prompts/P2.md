```text
### 4. Problem Specification: P2 — Form a Valid Arithmetic Equation (`19_q2.pl`)
Given a list of non-negative integers `n1, n2, ..., nk`, insert the operators `+`, `-`, `*`, `/` and exactly one `=` between the numbers (using every number once, in the given order, with optional parentheses) so that both sides of the equation have the same integer value.

**Expression & Evaluation Rules:**
- An equation is `L=R`, where `L` is an expression over `n1..nj` and `R` is an expression over `n(j+1)..nk` for some `1 <= j < k`. Every number is used exactly once, in order.
- An expression is a single number, or two expressions joined by `+`, `-`, `*`, or `/`, optionally in parentheses.
- No unary minus, and digits of different numbers are never joined into a bigger number.
- Values of sub-expressions may be negative (e.g., `3-5`).
- Division is allowed ONLY when it is exact (integer result with no remainder) and the divisor is not zero. This applies to every division inside an expression, not just the last.
- Both sides must evaluate to the same integer value.

**Canonical Output Format:**
- An equation must be returned as an **SWI-Prolog string** (not an atom, not a code list) with no spaces, e.g., `"4*2=5+3"`.
- Numbers are written in decimal.
- `*` and `/` bind tighter than `+` and `-`. Operators are left-associative.
- A **left** operand is wrapped in parentheses ONLY if its top operator has strictly lower precedence than its parent's.
- A **right** operand is wrapped in parentheses if its top operator has the same or lower precedence than its parent's.
- A single number is never in parentheses.
- Examples: `(4+2)*3`, `4+2*3`, `8/4*2` (for `(8/4)*2`), `8/(4*2)`, `1-2-3` (for `(1-2)-3`), `1-(2-3)`, `1+(2+3)`, `1+2+3` (for `(1+2)+3`). Note that `1+(2+3)` and `1+2+3` are different trees and count as different equations.

**Tasks:**
- **P2.a:** `generate_equation(List, Equation)` unifies `Equation` with one valid equation for `List`. Must **fail** (not loop, not raise an error) if no valid equation exists, including for lists of length 0 or 1.
- **P2.b:** `all_equations(List, Equations)` unifies `Equations` with the list of **all** valid equations, without duplicates, sorted by `sort/2` (standard order of terms); if none, `Equations = []`. `count_equations(List, N)` gives the length of that list.

**Internal Expression Tree Convention (to keep predicates consistent):**
Represent expression trees as `num(N)` for a single integer and `op(Op, Left, Right)` where `Op` is one of `+`, `-`, `*`, `/`.

Confirm in one sentence that you have read `skill.md` and these rules, and wait for Prompt 1. Do not write any code yet.
```
