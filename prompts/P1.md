# Prompts for P1: Department Assignment Puzzle, Reloaded

## Master Prompt
```text
You are an expert SWI-Prolog 9.x developer assisting me with an assignment (`19_q1.pl` and `P1_REPORT.md`).

### 1. Mandatory Reference: `skill.md`
- Always read, consult, and strictly follow the conventions, patterns, and guidelines in my `skill.md` file during every code generation, testing, and review step.
- If `skill.md` conflicts with any hard assignment constraint below, flag the conflict before writing code; otherwise, apply `skill.md` to all Prolog code you produce.

### 2. Strict Workflow Rule (Decomposition)
- We are working strictly incrementally: ONE unit of work per prompt (one predicate, one clause, one test file, one report, or one review).
- NEVER generate the complete solution, extra helper predicates I did not ask for, or future steps ahead of time.
- Output ONLY the exact code or text requested in the current prompt.

### 3. Environment & Hard Constraints
- Target environment: SWI-Prolog 9.x.
- Allowed libraries ONLY: `lists`, `apply`, `yall`, `aggregate`.
- STRICTLY FORBIDDEN: `assert`, `retract`, global variables (`b_setval`, `nb_setval`), `halt/0`, and `initialization` directives.
- Do not hard-code any puzzle solutions; derive them from the clues.
- Do not print anything other than what is explicitly specified.
- Execution context: `swipl -q -f 19_q1.pl -g main -t halt` and `swipl -q -f 19_q1.pl -g "<goal>" -t halt`.

### 4. Problem Specification: P1 — Department Assignment Puzzle, Reloaded
Four friends (Alex, Ben, Carla, Dana) each have a department, a favorite language, and a project preference. Every friend has a different value for each attribute (each of the four values is used exactly once):
- **Department:** `research`, `development`, `design`, `testing`
- **Favorite language:** `python`, `java`, `'c++'`, `javascript`
- **Project:** `'AI'`, `web`, `embedded`, `data`

**Representation:**
A solution is a Prolog list of four terms `p(Name, Dept, Lang, Project)` in the exact order `'Alex'`, `'Ben'`, `'Carla'`, `'Dana'`, using the exact atoms above (e.g., `[p('Alex', design, java, web), p('Ben', testing, python, data), ...]`). Each clue is written as its own clause `clue(N, Solution)` that succeeds exactly when clue number `N` holds in a fully filled-in `Solution`.

**Clues (1–8):**
1. The friend who prefers the `'AI'` project does not work in `research` and is not `'Dana'`.
2. `'Alex'` does not work in `development` and does not prefer `'c++'`.
3. The friend working in the `testing` department likes `python`.
4. `'Ben'` prefers `web` projects and does not work in `testing`.
5. The friend whose favorite language is `java` works in the `design` department.
6. `'Carla'`'s project preference is not `embedded`, and her department is not `development`.
7. `'Dana'`'s favorite language is not `java`, and she works in `research` or `testing`.
8. The friend who prefers `data` projects works in `research` and does not use `javascript`.

**Tasks:**
- **P1.a (solve):** `main/0` prints one solution that satisfies clues 1 to 8 as four lines in this exact format (in the order Alex, Ben, Carla, Dana, with no quotes around atoms):
    Alex = [research, python, AI]
    Ben = [development, java, web]
    Carla = [design, c++, embedded]
    Dana = [testing, javascript, data]

    (FORMAT ONLY NOT ACTUAL SOLUTION)

- **P1.b (count):** Define `count_solutions(Active, N)` where `Active` is a list of clue numbers (e.g., `[1,2,3,4,5,6,7,8]`) and `N` is the number of solutions satisfying exactly the clues in `Active` (ignoring all others), using `findall/3` or `aggregate_all/3`. Report in `P1_REPORT.md` the value of `N` for clues 1 to 8 and what it tells us about the puzzle.
- **P1.c (repair):** Add `clue(9, Solution)` so that `count_solutions([1,2,3,4,5,6,7,8,9], N)` gives `N = 1`. Place the English sentence of the clue in a comment on the line directly above it starting with `% CLUE 9:`. It must not mention any friend by name (refer only through attribute values, like clue 5), and it must be true in the one kept solution and false in every other solution of clues 1 to 8.

Confirm in one sentence that you have read `skill.md` and these rules, and wait for Prompt 1. Do not write any code yet.

```
