### 4. Problem Specification: S2 — Conditionally Insert into a Nested List (`19_q4.rkt`)
The function `(insert-if-short x lst n)` takes an atom `x`, a (possibly nested) list `lst`, and an integer `n` (`n >= 0`), and inserts `x` at the front of every list whose length is `< n`, at every level of nesting.

**Rules:**
- The length of a list is the number of its top-level elements (atoms or sublists), measured on the **original** list before any insertion.
- The top-level list is treated like every other list.
- Empty lists are not special: `'()` has length `0`, so it becomes `(x)` whenever `0 < n` (including an empty top-level list).
- Elements of `lst` are atoms (digits or symbols) or lists; there are no dotted pairs. `x` is any atom; `n >= 0`.

**Tasks:**
- **S2.a:** `(print-insert-result)` takes no arguments. It reads `x`, `lst`, and `n` in that order from stdin using `read`, then prints the resulting list with `display` followed by `newline` (no prompt or extra text).
- **S2.b:** Write your own `my-length` and `my-map` (using only allowed built-ins) and define `(insert-if-short x lst n)` using them.
- **S2.c:** Write a higher-order function `(make-inserter x len-ok?)` that returns a function of one argument (a list) which inserts `x` at the front of every list, at every level of nesting, whose original length satisfies `len-ok?` (a predicate taking one number). Then replace the definition of `insert-if-short` so it is defined using `make-inserter` (final file must contain only this single definition of `insert-if-short`).

**Examples (stdin -> stdout):**
- `42 ((1 2) (3 4 5) (6) ()) 3` -> `((42 1 2) (3 4 5) (42 6) (42))`
- `0 (((1) 2) (3) ((4 5 6) ())) 3` -> `((0 (0 1) 2) (0 3) (0 (4 5 6) (0)))`
- `7 () 3` -> `(7)`
- `7 () 0` -> `()`

Confirm in one sentence that you have read `skill.md` and these rules, and wait for Prompt 1. Do not write any code yet.
